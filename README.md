### 👋 About

I'm an AI-native product builder in Los Angeles. I use AI development tools every day to take products from idea to the app store and keep improving them in production. So far that's five shipped products across mobile, web, backend, payments, telephony and networking, used by thousands of people.

### 🤝 How I work with AI tools

- I use them to help people and teams do their own work faster. I work inside existing products, codebases and processes to improve them, not to start over.
- Claude Code and Cursor are my everyday tools: I write specs an agent can execute, direct and review what it produces, and verify it with tests.
- I know from practice where AI tooling speeds up specification, prototyping, testing and release work, and where it doesn't. I'll tell you which is which.
- I like working with everyone, technical or not, and directly with customers on real problems.
